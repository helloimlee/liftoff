THE GATE

It grades the work against what you said it should feel like.

Craft and feeling are separate verdicts and both have to pass. A build can be pixel-clean, token-perfect, fully accessible, and still be nothing. That is the failure nobody else checks for.

THE LOOP

Four things happen before anything gets built.

Each one is cheap. Skipping them is what costs the afternoon.

CLASSIFY

Read the room first

Interface or static asset, and what you attached. Stated out loud in one line so you can correct it in a sentence instead of at hour three.

TARGET

Name the feeling

Three feelings and a peak moment, written down. Without this, "good" means "it renders" and the review is a formality.

IDEA

Say it in one sentence

A mechanism, not a mood. If the description could apply to nine other projects, you have a style and not an idea. Two minutes, and it kills the most expensive failure in the loop.

BUILD · GRADE

Read the real stylesheet, then earn the pass

Pulls your live tokens before inventing a single value, sweeps the output against known AI tells automatically, and hands the result to fresh eyes that never self-grade.

HONEST ABOUT ITSELF

It chains other skills, and degrades instead of breaking.

You almost certainly do not have all of these. That is fine and expected. Run doctor.sh after installing and it prints exactly what you have, what you don't, and what each absence costs you.

resonancewithout it · the gate gets weaker
impeccablewithout it · planning only, nothing gets built
design-deathmatchwithout it · single exploration, no tournament
accessibility-reviewwithout it · a11y goes unchecked
gsap · threejs · motionwithout them · no timeline motion or 3D

None of it is required. On its own, Liftoff is still a charter loop with an emotional target and an idea gate, which is most of the value. Missing pieces get skipped and named in the run summary rather than silently dropped.
